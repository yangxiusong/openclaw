# 业务数据分析

## 概述

本技能专注于业务指标分析和数据驱动决策，提供从数据采集、指标计算到洞察输出的完整分析能力，帮助用户用数据驱动业务增长。

## 核心能力

### 1. 公众号数据分析

- 阅读量分析
- 点赞/收藏/转发
- 粉丝增长
- 文章转化
- 用户画像

### 2. 小红书数据分析

- 曝光量分析
- 点击率（CTR）
- 互动率（点赞/收藏/评论）
- 涨粉分析
- 爆文分析

### 3. 用户增长分析

- DAU/MAU（日/月活）
- 新增用户
- 留存率（次日/7 日/30 日）
- 流失率
- 用户分层

### 4. 销售数据分析

- GMV（成交总额）
- 订单量
- 客单价（AOV）
- 转化率
- 复购率

### 5. 运营指标分析

- 漏斗转化
- 用户生命周期价值（LTV）
- 获客成本（CAC）
- ROI（投资回报率）

### 6. 数据可视化

- 趋势图表
- 对比图表
- 分布图表
- 仪表板设计
- 自动化报表

## 指标体系

### 公众号核心指标

**传播指标**

```
阅读量 = 文章被阅读次数
阅读率 = 阅读量 / 粉丝数 × 100%
分享率 = 分享次数 / 阅读量 × 100%
收藏率 = 收藏次数 / 阅读量 × 100%
```

**互动指标**

```
点赞率 = 点赞数 / 阅读量 × 100%
评论率 = 评论数 / 阅读量 × 100%
互动率 = (点赞 + 评论 + 分享) / 阅读量 × 100%
```

**增长指标**

```
新增粉丝 = 当日新关注人数
取消关注 = 当日取关人数
净增粉丝 = 新增 - 取消
粉丝增长率 = 净增粉丝 / 总粉丝数 × 100%
```

**转化指标**

```
阅读原文点击率 = 点击次数 / 阅读量 × 100%
二维码扫描率 = 扫描次数 / 阅读量 × 100%
转化率 = 转化人数 / 阅读量 × 100%
```

### 小红书核心指标

**曝光指标**

```
曝光量 = 笔记被展示次数
点击量 = 笔记被点击次数
点击率 (CTR) = 点击量 / 曝光量 × 100%
```

**互动指标**

```
点赞数 = 笔记获得点赞
收藏数 = 笔记被收藏次数
评论数 = 笔记评论数量
互动总数 = 点赞 + 收藏 + 评论
互动率 = 互动总数 / 点击量 × 100%
```

**增长指标**

```
涨粉数 = 通过笔记新增粉丝
涨粉率 = 涨粉数 / 曝光量 × 100%
```

**爆文指标**

```
爆文率 = 爆文数量 / 总笔记数 × 100%
爆文标准：点赞>1000 或 收藏>500
```

### 用户增长指标

**活跃指标**

```
DAU（日活跃用户）= 当日活跃用户数
MAU（月活跃用户）= 当月活跃用户数
DAU/MAU = 用户粘性指标（0.2 以上为健康）
```

**留存指标**

```
次日留存率 = 第 2 日活跃用户 / 第 1 日新增用户 × 100%
7 日留存率 = 第 7 日活跃用户 / 第 1 日新增用户 × 100%
30 日留存率 = 第 30 日活跃用户 / 第 1 日新增用户 × 100%
```

**流失指标**

```
流失率 = 流失用户数 / 总用户数 × 100%
流失用户 = 超过 N 天未活跃的用户
```

### 销售指标

**规模指标**

```
GMV（成交总额）= 所有订单金额总和
订单量 = 成交订单数量
客单价 (AOV) = GMV / 订单量
```

**转化指标**

```
转化率 = 付费用户数 / 访问用户数 × 100%
下单转化率 = 下单用户数 / 访问用户数 × 100%
支付转化率 = 支付用户数 / 下单用户数 × 100%
```

**复购指标**

```
复购率 = 复购用户数 / 总用户数 × 100%
复购频次 = 总订单数 / 总用户数
用户生命周期价值 (LTV) = 客单价 × 复购频次 × 毛利率
```

**成本指标**

```
获客成本 (CAC) = 营销费用 / 新增用户数
投资回报率 (ROI) = (收入 - 成本) / 成本 × 100%
盈亏平衡点 = 固定成本 / (客单价 - 变动成本)
```

## 工作流

### 工作流 1: 公众号数据分析

**步骤 1: 数据收集**

```
从公众号后台导出：
- 用户分析（粉丝数据）
- 图文分析（单篇数据）
- 菜单分析（点击数据）
- 消息分析（互动数据）
```

**步骤 2: 核心指标计算**

```python
# 阅读率分析
reading_rate = total_reads / total_followers * 100

# 互动率分析
engagement_rate = (likes + comments + shares) / total_reads * 100

# 粉丝增长率
follower_growth = (new_followers - unfollowers) / total_followers * 100
```

**步骤 3: 趋势分析**

```
- 阅读量趋势（日/周/月）
- 粉丝增长趋势
- 互动率变化
- 爆文识别（阅读>平均 2 倍）
```

**步骤 4: 对比分析**

```
- 不同文章类型对比
- 不同发布时间对比
- 不同标题风格对比
- 与行业基准对比
```

**步骤 5: 输出洞察**

```markdown
## 核心发现

- 最佳发布时间：周三 20:00
- 最佳内容类型：教程类
- 平均阅读率：5.2%
- 爆文率：15%

## 建议

- 增加教程类内容
- 固定周三、周日发布
- 优化标题，提升点击率
```

### 工作流 2: 小红书爆文分析

**步骤 1: 数据收集**

```
从创作中心导出：
- 笔记数据（曝光/点击/互动）
- 粉丝数据（增长/画像）
- 直播数据（观看/转化）
```

**步骤 2: 爆文识别**

```python
# 爆文标准
def is_viral(note):
    return note['likes'] > 1000 or note['collects'] > 500

# 爆文率
viral_rate = viral_notes / total_notes * 100
```

**步骤 3: 爆文特征分析**

```
分析爆文的共同特征：
- 标题关键词
- 封面风格
- 内容类型
- 发布时间
- 标签使用
```

**步骤 4: 优化建议**

```
基于爆文特征：
- 标题公式优化
- 封面设计建议
- 内容方向调整
- 发布时间优化
- 标签策略
```

### 工作流 3: 漏斗转化分析

**步骤 1: 定义漏斗**

```
典型电商漏斗：
访问 → 浏览 → 加购 → 下单 → 支付
```

**步骤 2: 计算转化率**

```python
# 各阶段转化率
browse_rate = browsers / visitors * 100
cart_rate = cart_users / browsers * 100
order_rate = order_users / cart_users * 100
pay_rate = pay_users / order_users * 100

# 整体转化率
conversion_rate = pay_users / visitors * 100
```

**步骤 3: 识别瓶颈**

```
找出转化率最低的环节：
- 访问→浏览低：吸引力不足
- 浏览→加购低：产品力问题
- 加购→下单低：价格/决策问题
- 下单→支付低：支付流程问题
```

**步骤 4: 优化建议**

```
针对瓶颈环节：
- 优化页面设计
- 调整价格策略
- 简化支付流程
- 增加信任背书
```

### 工作流 4: 用户留存分析

**步骤 1: 定义留存**

```
次日留存：第 2 天还活跃的用户
7 日留存：第 7 天还活跃的用户
30 日留存：第 30 天还活跃的用户
```

**步骤 2: 计算留存率**

```python
# 同期群分析
cohort = users_who_joined_on_day_1
retention_day_1 = active_on_day_2 / cohort * 100
retention_day_7 = active_on_day_8 / cohort * 100
retention_day_30 = active_on_day_31 / cohort * 100
```

**步骤 3: 留存曲线**

```
绘制留存曲线：
- X 轴：天数
- Y 轴：留存率
- 对比不同时期用户
```

**步骤 4: 留存分析**

```
分析留存用户特征：
- 行为特征（使用频次、时长）
- 功能使用（核心功能使用率）
- 用户画像（地域、年龄、来源）
```

**步骤 5: 提升建议**

```
基于分析：
- 新用户引导优化
- 核心功能推广
- 召回策略设计
- 激励机制优化
```

## 注意事项

1. **数据准确性** - 确保数据来源可靠，计算准确
2. **指标一致性** - 统一指标定义和计算口径
3. **时间对比** - 注意同比、环比的可比性
4. **异常值处理** - 识别并合理解释异常值
5. **隐私保护** - 脱敏处理用户数据
6. **数据时效** - 标注数据日期，定期更新
7. **结论验证** - 重要结论需要交叉验证
