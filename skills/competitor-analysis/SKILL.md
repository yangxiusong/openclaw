# 竞品分析框架

## 概述

本技能提供系统化的竞品分析方法论和工具，帮助用户全面了解市场竞争格局，识别差异化机会，制定有效的竞争策略。

## 分析框架

### 框架 1: 竞品分层模型

**第一层：直接竞品**

- 目标用户相同
- 核心价值相似
- 功能高度重合
- 例：钉钉 vs 企业微信

**第二层：间接竞品**

- 目标用户部分重合
- 解决类似问题
- 方案不同
- 例：钉钉 vs 飞书

**第三层：潜在竞品**

- 不同行业但可跨界
- 拥有用户/技术/渠道优势
- 有进入可能性
- 例：字节 vs 腾讯

### 框架 2: 功能对比矩阵

| 功能模块   | 我方    | 竞品 A | 竞品 B | 竞品 C | 权重 |
| ---------- | ------- | ------ | ------ | ------ | ---- |
| 核心功能 1 | ✅      | ✅     | ❌     | ✅     | 30%  |
| 核心功能 2 | ✅      | ❌     | ✅     | ✅     | 25%  |
| 特色功能 1 | ❌      | ✅     | ❌     | ❌     | 15%  |
| 用户体验   | 中      | 优     | 良     | 中     | 20%  |
| 价格       | 中      | 高     | 低     | 中     | 10%  |
| **总分**   | **100** | **95** | **80** | **90** |      |

### 框架 3: SWOT 分析

**Strengths（优势）**

- 我们比竞品强的地方
- 核心竞争力
- 独特资源

**Weaknesses（劣势）**

- 我们比竞品弱的地方
- 需要改进的地方
- 资源短板

**Opportunities（机会）**

- 市场空白点
- 竞品未满足的需求
- 趋势红利

**Threats（威胁）**

- 竞品的优势
- 市场风险
- 潜在进入者

### 框架 4: 商业模式画布

```
1. 客户细分 - 服务谁？
2. 价值主张 - 提供什么价值？
3. 渠道通路 - 如何触达用户？
4. 客户关系 - 如何维系用户？
5. 收入来源 - 如何赚钱？
6. 核心资源 - 需要什么资源？
7. 关键业务 - 做什么事？
8. 重要合作 - 和谁合作？
9. 成本结构 - 花多少钱？
```

## 工作流

### 工作流 1: 系统性竞品分析

**步骤 1: 确定分析目标**

```
- 分析目的：产品优化/市场进入/投资决策
- 分析范围：哪些竞品？哪些维度？
- 输出形式：报告/PPT/表格
- 时间节点：完成时间
```

**步骤 2: 竞品识别和筛选**

```
搜索："[行业] 主要厂商"
搜索："[行业] 竞品对比"
搜索："[产品类别] 推荐"
输出：竞品清单（10-20 家）
筛选：选出 5-8 家重点分析
```

**步骤 3: 信息收集**
对每家竞品收集：

- 官网信息（产品、定价、案例、团队）
- 用户评价（应用商店、社交媒体、论坛）
- 媒体报道（融资、合作、战略）
- 招聘信息（技术栈、团队规模）
- 专利信息（技术布局）

**步骤 4: 深度分析**

- 产品体验（注册、使用全流程）
- 功能拆解（核心功能、特色功能）
- 定价分析（套餐、折扣、付费点）
- 用户分析（画像、评价、投诉）
- 营销分析（渠道、内容、活动）

**步骤 5: 对比总结**

- 功能对比矩阵
- SWOT 分析
- 竞争格局图
- 差异化机会点

**步骤 6: 输出报告**

```markdown
# 竞品分析报告

## 执行摘要

## 市场概况

## 竞品详细分析

## 对比总结

## 战略建议

## 附录
```

### 工作流 2: 快速竞品扫描

**适用场景：** 时间有限，需要快速了解竞争格局

**30 分钟快速扫描**

```
1. 搜索竞品名单（5 分钟）
2. 浏览竞品官网（10 分钟）
3. 查看用户评价（10 分钟）
4. 总结关键发现（5 分钟）
```

**输出：** 一页纸竞品概览

### 工作流 3: 功能差距分析

**步骤 1: 列出功能清单**

```
- 核心功能（必须有）
- 重要功能（应该有）
- 锦上添花（可以有）
```

**步骤 2: 对比分析**

```
对每个功能标注：
✅ 我们有且比竞品好
⭕ 我们有但和竞品相当
❌ 我们没有但竞品有
```

**步骤 3: 优先级排序**

```
优先级 = 用户需求强度 × 竞争差距 × 实现难度
```

## 注意事项

1. **客观公正** - 避免主观偏见，基于事实分析
2. **数据时效** - 标注数据日期，定期更新
3. **信息来源** - 优先官方来源，交叉验证
4. **合法合规** - 不使用非法手段获取信息
5. **保密原则** - 内部报告，注意保密
6. **动态追踪** - 竞品分析是持续过程
