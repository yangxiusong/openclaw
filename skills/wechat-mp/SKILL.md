# 微信公众号运营

## 概述

本技能提供微信公众号全链路运营能力，从内容创作到发布管理，从用户运营到数据分析，帮助用户高效运营公众号并实现业务增长。

**注意：** 完整 API 功能需要微信公众号后台配置和 API 权限。

### 1. 内容管理

- 图文素材创建
- 草稿箱管理
- 文章发布
- 定时群发
- 历史文章管理

### 2. 素材管理

### 3. 用户管理

### 4. 菜单管理

- 自定义菜单创建
- 菜单项配置
- 菜单更新
- 菜单数据分析

### 5. 消息管理

- 消息分析（发送/接收）

## 公众号类型和权限

### 公众号类型

**订阅号**

- 定位：信息传播
- 群发：每天 1 次
- 显示：折叠在订阅号文件夹
- 适用：媒体、个人、企业品牌

**服务号**

- 定位：服务交互
- 群发：每月 4 次
- 显示：显示在聊天列表
- 适用：企业、组织服务

**企业微信**

- 定位：企业内部沟通
- 群发：不限次数
- 显示：企业微信应用
- 适用：企业内部管理

### API 权限

**基础权限（所有类型）**

- 素材管理
- 自定义菜单
- 自动回复
- 用户管理

**高级权限（认证后）**

- 模板消息
- 客服接口
- 用户标签
- 数据统计

**特殊权限（需申请）**

- 微信支付
- 卡券功能
- 小程序关联
- 开放平台

## 工作流

### 工作流 1: 公众号文章发布

**步骤 1: 内容创作**

```
使用 content-creation 技能：
- 撰写文章（1500-5000 字）
- 优化标题（10w+ 公式）
- 排版美化
- 配图制作
```

**步骤 2: 素材上传**

```
- 上传封面图（900x383px）
- 上传文中图片
- 上传缩略图
```

**步骤 3: 创建草稿**

```
- 填写标题、作者、摘要
- 插入图文内容
- 设置封面和摘要
- 保存为草稿
```

**步骤 4: 预览和修改**

```
- 发送到手机预览
- 检查格式、链接、图片
- 修改完善
```

**步骤 5: 群发或定时**

```
- 立即群发（订阅号每天 1 次）
- 或设置定时发送
- 选择发送范围（全部/标签/分组）
```

**步骤 6: 数据分析**

```
发布后追踪：
- 阅读量（1h/24h/7 天）
- 分享率
- 点赞率
- 新增粉丝
```

### 工作流 2: 用户标签管理

**步骤 1: 标签体系设计**

```
推荐标签维度：
- 用户来源（扫码/搜索/引流）
- 用户属性（地域/年龄/性别）
- 行为特征（活跃/沉睡/付费）
- 兴趣偏好（内容类型偏好）
```

**步骤 2: 创建标签**

```
- 创建标签分类
- 设置标签名称
- 定义标签规则
```

**步骤 3: 用户打标**

```
方式：
- 手动打标（后台操作）
- 自动打标（API 规则）
- 批量打标（Excel 导入）
```

**步骤 4: 标签应用**

```
应用场景：
- 精准群发（按标签推送）
- 个性化菜单（按标签展示）
- 用户分层运营
```

### 工作流 3: 自动回复配置

**步骤 1: 回复类型设计**

```
类型：
- 被关注回复（新用户）
- 关键词回复（触发词）
- 消息回复（默认）
```

**步骤 2: 内容准备**

```
- 欢迎语文案
- 关键词库
- 回复素材（图文/图片/文字）
```

**步骤 3: 规则配置**

```
关键词回复规则：
- 完全匹配（精确词）
- 模糊匹配（包含词）
- 正则匹配（高级模式）
```

**步骤 4: 测试优化**

```
- 测试关键词触发
- 检查回复内容
- 优化回复话术
```

### 工作流 4: 菜单优化

**步骤 1: 菜单结构设计**

```
推荐结构（3 个主菜单，每个最多 5 个子菜单）：
- 关于我们（品牌介绍/联系方式）
- 产品服务（产品列表/购买入口）
- 互动中心（活动/客服/社区）
```

**步骤 2: 菜单内容配置**

```
菜单类型：
- 跳转网页（H5/小程序）
- 发送消息（图文/文字）
- 触发事件（点击事件）
```

**步骤 3: 菜单发布**

```
- 保存并发布
- 菜单 24 小时内生效
- 用户端需重新关注或清除缓存
```

**步骤 4: 数据分析**

```
追踪指标：
- 各菜单点击次数
- 点击率
- 转化效果
- 优化建议
```

## 运营策略

### 内容策略

**选题规划**

```
内容类型配比：
- 干货教程（40%）- 建立专业形象
- 行业资讯（20%）- 保持时效性
- 案例分享（20%）- 增强说服力
- 互动活动（10%）- 提升参与度
- 品牌故事（10%）- 传递价值观
```

**发布节奏**

```
推荐频率：
- 订阅号：每天 1 篇（固定时间）
- 服务号：每周 1-2 篇（重点内容）

最佳时间：
- 早高峰：7:00-9:00
- 午休：12:00-13:00
- 晚高峰：20:00-22:00
```

**标题优化**

```
爆款标题公式：
- 数字 + 结果："30 天瘦 10 斤的 5 个方法"
- 痛点 + 方案："总是存不下钱？这个方法是关键"
- 悬念 + 反差："所有人都错了，这才是真相"
- 权威 + 利益："清华教授推荐：这 3 个习惯"
```

### 用户增长策略

**拉新渠道**

```
- 内容引流（优质内容自然增长）
- 活动引流（裂变活动）
- 付费引流（广点通/朋友圈广告）
- 渠道引流（其他平台导流）
- 线下引流（二维码/活动）
```

**留存策略**

```
- 新用户欢迎流程（关注后自动回复）
- 定期优质内容推送
- 用户分层运营（标签管理）
- 互动活动（留言/投票/抽奖）
- 会员体系（积分/等级/权益）
```

**转化策略**

```
- 软性植入（内容中自然推荐）
- 阅读原文跳转（H5/小程序）
- 菜单栏入口（固定转化路径）
- 客服引导（1 对 1 沟通）
- 限时活动（促使用户决策）
```

### 数据分析策略

**核心指标**

```
增长指标：
- 新增粉丝数
- 净增粉丝数
- 粉丝增长率

内容指标：
- 平均阅读率
- 分享率
- 点赞率
- 爆文率

转化指标：
- 阅读原文点击率
- 菜单点击率
- 转化率
```

**分析方法**

```
- 趋势分析（日/周/月）
- 对比分析（不同内容类型）
- 漏斗分析（阅读→转化）
- 用户分层（新/老/活跃/沉睡）
```

## API 接口参考

### 素材管理

```
上传临时素材：POST /cgi-bin/media/upload
上传永久素材：POST /cgi-bin/material/add_material
获取素材列表：POST /cgi-bin/material/batchget_material
删除素材：POST /cgi-bin/material/del_material
```

### 用户管理

```
获取用户列表：POST /cgi-bin/user/get
获取用户信息：POST /cgi-bin/user/info
设置用户标签：POST /cgi-bin/tags/members/batchtagging
取消用户标签：POST /cgi-bin/tags/members/batchuntagging
```

### 消息发送

```
群发消息：POST /cgi-bin/message/mass/sendall
模板消息：POST /cgi-bin/message/template/send
客服消息：POST /cgi-bin/message/custom/send
```

### 菜单管理

```
创建菜单：POST /cgi-bin/menu/create
查询菜单：GET /cgi-bin/menu/get
删除菜单：POST /cgi-bin/menu/delete
```

### 数据统计

```
用户分析：POST /cgi-bin/datacube/getusersummary
图文分析：POST /cgi-bin/datacube/getarticlesummary
菜单分析：POST /cgi-bin/datacube/getmenulist
```

## 注意事项

1. **发布限制** - 订阅号每天 1 次，服务号每月 4 次
2. **内容合规** - 遵守微信平台规范，不违规
3. **版权保护** - 使用正版素材，注意版权
4. **用户隐私** - 保护用户信息，不泄露
5. **API 限制** - 注意 API 调用频率限制
6. **审核时间** - 群发需要审核，预留时间
7. **备份习惯** - 重要内容本地备份
