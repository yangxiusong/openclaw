# 内容创作与排版

## 概述

本技能提供全平台内容创作能力，从公众号长文到小红书笔记，从营销文案到视频脚本，帮助用户高效产出高质量内容。

## 核心能力

### 1. 公众号文章

- 长文撰写（1500-5000 字）
- 标题优化（10w+ 爆款公式）
- 排版美化（Markdown/HTML）
- 配图建议
- 引导互动设计

### 2. 小红书笔记

- 笔记文案（300-800 字）
- 标题党技巧（吸引点击）
- 标签策略（#话题选择）
- 表情包使用
- 封面图建议

### 3. 社交媒体文案

- 朋友圈文案
- 微博短文案
- 社群运营话术
- 活动宣传文案

### 4. 营销内容

- 产品详情页
- 促销文案
- 品牌故事
- 用户案例

### 5. 视频脚本

- 口播脚本
- 分镜脚本
- 短视频脚本（30s/60s）
- 直播话术

## 快速开始

```
1. 确定主题 → 2. 搭建框架 → 3. 撰写初稿 → 4. 优化标题 → 5. 排版美化
```

```
1. 选话题 → 2. 写标题（3-5 个备选）→ 3. 写正文 → 4. 加标签 → 5. 配图建议
```

## 公众号文章

### 爆款标题公式

**公式 1: 数字 + 结果 + 时间**

```
"30 天瘦 10 斤，我做到了这 5 件事"
"3 个技巧，让你的阅读速度提升 10 倍"
```

**公式 2: 痛点 + 解决方案**

```
"孩子不听话？试试这招，亲测有效"
"总是存不下钱？这个方法是关键"
```

**公式 3: 反差 + 悬念**

```
"月薪 3 千到 3 万，我只做对了一件事"
"所有人都错了，这才是 XXX 的真相"
```

**公式 4: 权威背书 + 利益点**

```
"清华教授推荐：这 3 个习惯改变一生"
"医生不会告诉你：XXX 的真相"
```

### 文章结构模板

**模板 1: 问题 - 分析 - 解决**

```markdown
# 标题

## 引言（引发共鸣）

- 描述痛点场景
- 提出问题

## 问题分析

- 原因 1
- 原因 2
- 原因 3

## 解决方案

- 方法 1（步骤 + 案例）
- 方法 2（步骤 + 案例）
- 方法 3（步骤 + 案例）

## 总结

- 核心要点回顾
- 行动呼吁

## 互动引导

- 提问引发评论
- 引导转发收藏
```

**模板 2: 清单体**

```markdown
# 标题

## 引言

- 为什么需要这个清单
- 清单的价值

## 清单内容

1. 第一条（详细说明 + 案例）
2. 第二条（详细说明 + 案例）
3. 第三条（详细说明 + 案例）
   ...

## 总结

- 核心要点
- 行动建议
```

**模板 3: 故事 + 道理**

```markdown
# 标题

## 故事开头

- 人物 + 场景 + 冲突

## 故事发展

- 转折点
- 关键事件

## 故事高潮

- 最大冲突
- 关键选择

## 故事结局

- 结果
- 收获

## 道理升华

- 从故事中提炼的道理
- 如何应用到读者生活
```

### 排版规范

**标题层级**

```markdown
# 主标题（文章标题）

## 一级标题（章节）

### 二级标题（小节）

#### 三级标题（细节）
```

**强调方式**

```markdown
**加粗** - 重点内容
_斜体_ - 强调语气

> 引用 - 名人名言、重点引用
> `代码` - 专业术语、代码
```

**列表使用**

```markdown
- 无序列表（并列项）

1. 有序列表（步骤/排名）

- [ ] 任务列表（待办事项）
```

**分隔和间距**

```markdown
--- # 分隔线

     # 空行（段落间距）
```

### 标签策略

**标签类型**

- 大流量标签（100w+ 笔记）：#护肤 #穿搭 #美食
- 中流量标签（10w-100w）：#护肤分享 #日常穿搭
- 精准标签（1w-10w）：#油皮护肤 #小个子穿搭
- 品牌标签：#兰蔻 #优衣库

**标签数量**

- 最佳：5-8 个
- 最少：3 个
- 最多：10 个

**标签组合公式**

```
2 个大流量 + 3 个中流量 + 2 个精准 + 1 个品牌
```

## 文案创作技巧

### AIDA 模型

```
Attention（注意）- 吸引眼球
Interest（兴趣）- 引发兴趣
Desire（欲望）- 激发欲望
Action（行动）- 促进行动
```

### FAB 法则

```
Feature（属性）- 产品是什么
Advantage（作用）- 有什么用
Benefit（益处）- 对用户有什么好处
```

### 场景化描写

```
❌ "这个枕头很舒服"
✅ "躺上去就像被云朵包围，颈椎的酸痛感瞬间消失"

❌ "这个课程很好"
✅ "学完就能上手，3 天做出你的第一个作品"
```

## 内容改写和润色

### 改写技巧

**同义词替换**

```
原句："这个方法很有效"
改写："这个方案效果显著"
```

**句式变换**

```
原句："你应该每天运动"
改写："每天运动，你会收获..."
```

**增加细节**

```
原句："这个产品很好用"
改写："这个产品操作简单，老人小孩都能轻松上手"
```

### 润色检查清单

- [ ] 标题是否吸引人？
- [ ] 开头是否抓人？
- [ ] 逻辑是否清晰？
- [ ] 语言是否流畅？
- [ ] 是否有错别字？
- [ ] 是否有行动呼吁？
- [ ] 是否符合平台调性？

## 注意事项

1. **原创性** - 避免抄袭，保持原创
2. **真实性** - 真实体验，不夸大其词
3. **合规性** - 遵守平台规则，不违规
4. **版权** - 使用正版素材，注意版权
5. **隐私** - 保护用户隐私，不泄露信息
6. **价值观** - 传递正能量，符合主流价值观
