# 网络信息采集与市场调研

## 概述

本技能提供完整的网络信息采集和市场调研能力，帮助用户快速获取、整理和分析网络信息。

## 核心能力

### 1. 网络搜索

- 使用 Brave Search API 进行精准搜索
- 支持时间范围、地区、语言过滤
- 批量搜索结果提取

### 2. 内容抓取

- 网页内容提取（HTML → Markdown）
- 批量页面信息采集
- 结构化数据抽取

### 3. 竞品分析

- 竞品网站信息采集
- 产品功能对比
- 定价策略分析
- 用户评价收集

### 4. 行业研究

- 行业报告收集
- 市场趋势分析
- 政策法规调研
- 技术发展追踪

### 5. 用户调研

- 用户评论分析
- 社交媒体舆情
- 需求痛点收集
- 用户画像构建

## 快速开始

### 基础搜索

```bash
# 使用 web_search 工具
查询："大健康 SaaS 市场 2026"
参数：count=10, freshness="month"
```

### 内容抓取

```bash
# 使用 web_fetch 工具
URL: https://example.com/report
模式：markdown（默认）或 text
```

## 工作流

### 工作流 1: 竞品分析

**步骤 1: 确定竞品列表**

```
搜索："[行业关键词] 主要厂商"
搜索："[行业关键词] 竞品对比"
输出：竞品名单（5-10 家）
```

**步骤 2: 收集竞品信息**
对每家竞品收集：

- 官网信息（产品、定价、案例）
- 用户评价（知乎、小红书、行业论坛）
- 新闻动态（融资、合作、新产品）
- 社交媒体（公众号、微博内容）

**步骤 3: 对比分析**
创建对比表格：
| 维度 | 竞品 A | 竞品 B | 竞品 C | 我方 |
|------|--------|--------|--------|------|
| 核心功能 | | | | |
| 定价策略 | | | | |
| 目标用户 | | | | |
| 优势 | | | | |
| 劣势 | | | | |

**步骤 4: 输出报告**

- 市场格局概览
- 竞品详细分析
- 差异化机会点
- 建议行动项

### 工作流 2: 行业趋势研究

**步骤 1: 收集行业报告**

```
搜索："[行业] 市场规模 2026"
搜索："[行业] 发展趋势 report"
搜索："[行业] 白皮书 pdf"
时间范围：最近 12 个月
```

**步骤 2: 提取关键数据**

- 市场规模和增长率
- 用户规模和渗透率
- 主要驱动因素
- 挑战和风险

**步骤 3: 技术趋势分析**

```
搜索："[行业] AI 应用"
搜索："[行业] 技术创新"
搜索："[行业] 数字化转型"
```

**步骤 4: 输出洞察**

- 市场规模预测
- 关键趋势总结
- 机会点识别
- 战略建议

### 工作流 3: 用户需求调研

**步骤 1: 收集用户反馈**

```
搜索："[产品类型] 用户评价"
搜索："[产品类型] 使用体验"
搜索："[产品类型] 吐槽"
平台：知乎、小红书、微博、行业论坛
```

**步骤 2: 整理痛点清单**

- 功能痛点（缺少什么功能）
- 体验痛点（哪里不好用）
- 价格痛点（太贵/性价比低）
- 服务痛点（售后/支持问题）

**步骤 3: 需求分类**

- 必须有（Must have）
- 应该有（Should have）
- 可以有（Nice to have）

**步骤 4: 输出用户画像**

- 目标用户群体
- 核心需求场景
- 付费意愿分析
- 决策因素

## 搜索技巧

### 精准搜索语法

**时间过滤**

```
freshness="day"    # 24 小时内
freshness="week"   # 最近 7 天
freshness="month"  # 最近 30 天
freshness="year"   # 最近 1 年
```

**地区过滤**

```
country="CN"  # 中国
country="US"  # 美国
country="ALL" # 全球
```

**语言过滤**

```
language="zh"  # 中文
language="en"  # 英文
```

**高级搜索词**

```
"[关键词]"      # 精确匹配
[关键词] -排除   # 排除某个词
关键词 A OR 关键词 B  # 或关系
site:zhihu.com 关键词  # 限定网站
filetype:pdf 关键词   # 限定文件类型
```

## 注意事项

1. **数据时效性** - 标注数据采集日期，过时的数据要重新采集
2. **来源可信度** - 优先选择官方、权威来源
3. **交叉验证** - 重要数据从多个来源验证
4. **版权合规** - 注意引用规范，避免侵权
5. **隐私保护** - 不采集个人隐私信息
6. **反爬尊重** - 遵守 robots.txt，控制请求频率
